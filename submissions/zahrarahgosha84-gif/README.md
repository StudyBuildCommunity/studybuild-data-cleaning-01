# Data Cleaning روی دیتاست First Dataset

توی این پروژه یه دیتاست خرید اینترنتی (۶۱ ردیف، ۱۷ ستون) رو تمیز کردم. اینجا قدم‌به‌قدم می‌نویسم چیکار کردم و چرا، تا مشخص باشه هر تصمیمی از کجا اومده.

بعد از تمیزکاری، دیتاست از ۶۱ ردیف به **۵۶ ردیف** رسید.

---

### ۱. یه ردیف سن نداشت

یه مشتری مقدار age خالی داشت. چون فقط یه ردیف بود و اهمیت خاصی برای کل دیتاست نداشت، همون ردیف رو حذف کردم (نه کل ستون، چون سن برای تحلیل لازمه).

```python
df = df.dropna(subset=['age'])
```

---

### ۲. یه نفر سنش ۱۴۵ بود!

واضحه که این عدد اشتباهه، هیچکس ۱۴۵ سالش نمیشه. حذفش کردم چون معلوم نبود سن واقعیش چند بوده.

```python
df = df.drop(df[df['age'] == 145].index)
```

---

### ۳. یه customer_id دوبار تکرار شده بود

مشتری با id=1014 دوبار توی دیتاست بود. با drop_duplicates یکیش نگه داشته شد و اون یکی حذف شد.

```python
df = df.drop_duplicates(subset=['customer_id'])
```

---

### ۴. ستون gender اصلاً قابل اعتماد نبود

وقتی چک کردم دیدم تقریباً هر اسمی (مثل Ali, Sara, Reza...) هم با M و هم با F ثبت شده بود. یعنی این ستون از اول درست پر نشده بود، یه مشکل کلی بود نه چندتا خطای کوچیک.

چون جنسیت برای تحلیلم مهمه، نمی‌خواستم نادیده‌ش بگیرم. برای همین یه دیکشنری ساختم که هر اسم رو به جنسیت درستش (بر اساس رایج بودن اسم) وصل می‌کنه و ستون gender رو با اون جایگزین کردم:

```python
gender_map = {
    'Ali': 'M', 'Amir': 'M', 'Arash': 'M', 'Kimia': 'F',
    'Maryam': 'F', 'Mina': 'F', 'Neda': 'F', 'Parsa': 'M',
    'Reza': 'M', 'Sara': 'F', 'Sina': 'M', 'Zahra': 'F'
}

df['gender'] = df['first_name'].map(gender_map)
```

---

### ۵. یه نفر که هیچ خریدی نکرده بود، avg_order_value داشت

مشتری با id=1024، purchase_count=0 داشت (یعنی اصلاً خرید نکرده)، ولی avg_order_value مقدار غیرصفر (۶۳.۶۷) داشت. این منطقی نیست، چون بدون سفارش نباید میانگین ارزش سفارش هم داشته باشه. مقدارش رو صفر کردم تا با بقیه‌ی دیتاش (purchase_count=0 و total_spending=0) بخونه.

```python
df.loc[df['customer_id'] == 1024, 'avg_order_value'] = 0
```

---

### ۶. تاریخ عضویت به‌صورت متن بود

ستون signup_date رشته بود، نه تاریخ واقعی. تبدیلش کردم به datetime تا بعداً بشه محاسبات تاریخی (مثل طول عضویت) روش انجام داد.

```python
df['signup_date'] = pd.to_datetime(df['signup_date'])
```

---

### ۷. یه total_spending عجیب‌غریب داشتیم

برای customer_id=1030، وقتی purchase_count رو ضرب در avg_order_value کردم:

```
26 × 156.89 = 4079.14
```

ولی total_spending ثبت‌شده‌ش ۲۵۰۰۰ بود، یعنی حدود ۶ برابر بیشتر از چیزی که باید باشه. چون نمی‌شد فهمید کدوم عدد (purchase_count، avg_order_value یا total_spending) اشتباهه، این ردیف رو کلاً حذف کردم.

```python
df = df.drop(df[df['customer_id'] == 1030].index)
```

---

### ۸. یه total_spending هم خالی بود

یه ردیف دیگه هم مقدار خالی توی total_spending داشت. مثل مورد age، این ردیف رو هم حذف کردم.

```python
df = df.dropna(subset=['total_spending'])
```

---

## جمع‌بندی

بعد از همه‌ی این مراحل:

- دیگه هیچ مقدار خالی نیست
- ردیف تکراری نداریم
- سن غیرمنطقی حذف شد
- gender با اسم‌ها هم‌خونی داره
- purchase_count / avg_order_value / total_spending منطقی و سازگارن
- signup_date به فرمت درست تاریخ تبدیل شد

دیتاست نهایی ۵۶ ردیفه و آماده‌ی تحلیله.
